# 学刻 StudyTick 1.0.2

桌面小组件按你的要求改版，并修掉了一个会让锁屏通知消失的问题。

## 桌面小组件改版（2×2）

| 位置 | 内容 |
| --- | --- |
| 第一行 | 今日已学时间（如「今日已学 36 分」），替代原来的状态文字 |
| 第二行 | 灰色小字「剩余」+ 大号时间数字，例如 `剩余 1:51` |
| 第三行 | 进度条（浅灰轨道 + 蓝色进度） |
| 第四行 | 左侧「目标 2 时」，右侧加大的「开始」按钮 |

具体改动：

- 时间前面加了灰色小字「剩余」
- 顶部换成今日学习时间，「今日进行中」「学习中」这类状态文字全部移除
- 「开始」按钮明显加大：文字 11sp → 14sp，内边距 12×5dp → 22×9dp
- 时间字号 24sp，进度条 6dp 并改用自绘 drawable，保证轨道和进度在任何主题下都清晰可见

## 修复：锁屏通知消失

**问题**：应用进程被系统回收、或覆盖安装后重新打开，界面仍显示「专注中」，但前台服务没有恢复，于是通知消失、锁屏什么都看不到。

**修复**：
- 应用回到前台时，如果会话仍在进行，自动补启前台服务（幂等，不会重复计时）
- 新增开机 / 覆盖安装后自动恢复：`BOOT_COMPLETED` 与 `MY_PACKAGE_REPLACED` 时若会话仍在进行，重新拉起服务与通知

## 通知内容微调

标题行改为「学习中 · 已学 00:07:18」，右侧跟倒计时。这样锁屏一行内就能同时看到**已学**和**剩余**（之前只有剩余）。

## 升级说明

覆盖安装即可，打卡记录、每日目标、正在进行的计时都会保留。
