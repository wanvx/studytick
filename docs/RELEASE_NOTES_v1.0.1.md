# 学刻 StudyTick 1.0.1

修复真机反馈的两个问题。

## 修复

### 1. 锁屏不显示学习进度

**原因**：通知渠道用的是 `IMPORTANCE_LOW`，Android 会把它归入「静默通知」，而锁屏默认不展示静默通知，所以锁屏上看不到。

**改动**：
- 通知渠道换成 `IMPORTANCE_DEFAULT`（保持无声音、无震动，不会打扰），锁屏可以正常露出
- 新渠道 id 为 `study_timer_v2`，升级时自动删除旧的低重要性渠道，设置里不会出现两个「学习计时」
- 移除 `setSilent(true)`（这个标记同样会把通知压进静默分区）
- 通知类别改为 `CATEGORY_STOPWATCH`，并补上展开视图（BigText），锁屏/通知栏展开后能看到完整信息
- 正文顺序调整为「已学 … · 剩余 …」，右侧保留系统倒计时，每秒自动走，不额外耗电

### 2. 底部导航栏与系统导航键重叠

**原因**：应用开启了 edge-to-edge，但悬浮导航栏只留了固定 18dp 边距，没有避让系统导航栏（三键约 48dp、手势条约 24dp）。

**改动**：
- 悬浮导航栏改用 `navigationBarsPadding()`，跟随系统导航栏实际高度自动上移
- 三个页面底部留白从写死的 96dp 改为「系统导航栏高度 + 导航栏自身高度」动态计算，三键和手势两种模式下都不会遮挡内容

### 新增

- 个人页新增「锁屏与通知」入口：显示通知是否开启，点击直接跳到本应用的通知设置。部分品牌（小米 / 华为 / OPPO / vivo）有独立的「锁屏通知」开关，若锁屏仍不显示，在这里调整即可。

## 升级说明

直接覆盖安装即可，**打卡记录、每日目标、正在进行的计时都会保留**（数据库与 DataStore 都不做破坏性迁移）。
