# v1.0.3 · 小组件剩余时间显示到秒

发布日期：2026-11-08
versionCode：4
APK：`dist/StudyTick-1.0.3.apk`（11.5 MB，与 1.0.2 同签名，可直接覆盖安装）

## 改动

### 1. 统一剩余时间格式为「时:分:秒」

| 场景 | 1.0.2 | 1.0.3 |
| --- | --- | --- |
| 小组件 · 未开始 | 剩余 1:50（只有时和分） | 剩余 1:50:26 |
| 小组件 · 计时中 | 剩余 1:50:26（系统 Chronometer） | 剩余 1:50:26（不变） |
| 通知 / 锁屏 / 应用内 | 1:50:26 | 1:50:26（不变） |

原因：小组件静止态是 RemoteViews 静态文本，由 `TimeFmt.widget()` 生成，当时为了"看起来不跳动"省掉了秒；计时态用的是系统 `Chronometer`，格式固定为 `时:分:秒`，于是两处不一致。
现在静态文本也带秒——不学习时"剩余 = 目标 − 已学"本来就不变，秒数静止是正确的。

格式规则（两处一致）：
- 剩余 ≥ 1 小时：`1:50:26`
- 剩余 < 1 小时：`50:26`（分:秒）

### 2. 时间字号 24sp → 22sp

为三位数小时（如 `10:05:00`）预留宽度，避免在小尺寸启动器里被裁切。实测 2x2 卡片中 `1:50:26` 完整显示、无换行。

### 3. 选择器预览同步

`widget_preview.xml` 预览文案改为 `1:24:00`，与实际布局一致。

## 实测

- 模拟器（Pixel 4 AVD / Android 15）通过「我的 → 添加桌面小组件」重新添加，卡片显示 `剩余 1:50:26`
- 点击「开始」→ 按钮变「结束」，倒计时从 `1:51:09` 递减至 `1:50:52`，格式与静态一致
- 点击「结束」→ 回到静态显示，今日已学时间同步更新
- 截图：`dist/shots/widget-1.0.3.png`、`dist/shots/widget-1.0.3-full.png`

## 升级

覆盖安装即可，Room 数据库、每日目标、正在进行的计时会话均保留。
