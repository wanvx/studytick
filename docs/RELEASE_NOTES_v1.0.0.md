## 学刻 StudyTick 1.0.0

极简每日学习打卡应用。定一个每日目标，一键开始计时，看进度一点点填满圆环。

### 功能

- **主页**：270° 渐变圆环显示今日进度，中央是剩余时间，一键开始 / 结束学习
- **日历**：月历上以蓝色小块标记已打卡日期，下方是今日打卡卡片（开始计时、已学时间、剩余时间），达标后显示「已完成今日打卡」
- **我的**：设置每日学习时长、检查更新、添加桌面小组件、GitHub 仓库入口、清除打卡数据
- **桌面小组件**：2×2 卡片，显示今日状态、剩余时间与进度条；点卡片打开应用，点胶囊按钮直接开始 / 结束计时
- **锁屏 / 通知栏**：常驻通知展示已学时间、剩余时间、进度条与系统倒计时，锁屏即可看到
- **数据不丢**：Room + DataStore 持久化，覆盖安装升级后记录完整保留

### 安装

下载下方 `StudyTick-1.0.0.apk`，在手机上安装（需允许「安装未知来源应用」）。

- 包名：`com.studytick.app`
- 版本：1.0.0（versionCode 1）
- 最低系统：Android 8.0（API 26）
- 体积：约 11 MB
