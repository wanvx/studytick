# v1.1.0 更新日志

发布日期：2026-11-09

## 品牌焕新
- 应用更名 **学无止境**，全新简约图标：蓝白渐变底 + 几何「学」字图形，启动页、通知、桌面抽屉同步更新。

## 新功能：每周学习计划
- 新增**周目标**（默认 30 小时），在「我的」页以 1 小时为步进增减。
- **今日页**：圆环下方新增「本周」卡片，实时显示本周剩余时数、已完成时长与计划总时数。
- **日历页**：月历下方新增统计卡片，展示「本月已坚持 X 天」与「连续打卡 X 天」。
- **桌面小组件**：新增本周进度行，剩余/计划一目了然。

## 稳定性修复
- 冷启动时 WorkManager 初始化移至后台线程，修复偶发的启动卡顿（ANR）。
- 小组件刷新逻辑收紧，减少不必要的系统广播。

## 说明
- 覆盖安装即可，打卡数据、每日目标、周计划、进行中的计时全部保留。
- 应用内「我的 → 软件更新 → 检查」可直接获取本版本。
