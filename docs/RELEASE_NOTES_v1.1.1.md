# v1.1.1 更新日志

发布日期：2026-11-23

## 连续打卡改为「按周」统计
- 统计口径从"连续天数"改为"**连续周数**"：一周（周一至周日）有 **5 天及以上**达标，该周即计为打卡成功。
- 连续周数从最近一个成功周往前累计，遇到不足 5 天的周即中断。
- 本周尚未凑满 5 天时**不计中断**，从上周继续计算，避免周中看到归零。

## 新增「共自习」总时长
- 日历页统计卡片新增第三列：**共自习 X 小时**（全部历史累计，保留一位小数）。
- 计时进行中实时增长。

## 界面
- 日历页统计卡片由两列改为三列：**本月已坚持 X 天 ｜ 连续打卡 X 周 ｜ 共自习 X 小时**。
- 字号微调至 16sp，窄屏下三列不折行。

## 说明
- 覆盖安装即可，历史打卡记录、每日目标与每周计划全部保留。
- 统计口径变化仅影响展示，不改动任何已存数据。
- 应用内「我的 → 软件更新 → 检查」可直接获取本版本。
